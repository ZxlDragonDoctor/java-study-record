# Java技术学习记录仓

一个综合性的Java技术学习项目集合，涵盖多种后端开发技术栈。

## 项目结构

| 目录 | 技术栈 | 说明 |
|------|--------|------|
| `ssm-studydemo` | SSM | Spring+SpringMVC+MyBatis框架学习示例 |
| `javaweb_workspace` | JavaWeb | JavaWeb工作空间 |
| `template` | SpringBoot | SpringBoot项目初始化模板 |
| `JDBC-test` | JDBC | JDBC数据库连接测试 |
| `MongoDB-Test` | MongoDB | MongoDB数据库操作测试 |
| `redis-demo` | Redis | Redis缓存演示项目 |
| `javaWeb-hive` | Hive | JavaWeb与Hive数据仓库集成 |
| `rabbitMqTest` | RabbitMQ | 消息队列测试项目 |
| `selenium` | Selenium | Web自动化测试 |
| `RestAssured` | REST | RESTful API接口测试 |
| `practicejava` | JavaSE | Java基础语法练习 |
| `ccfTest` | - | CCF相关测试 |
| `zxl_lqcode` | - | 代码练习项目 |
| `zxlTank` | JavaSE | 坦克大战游戏项目 |
| `exp-design` | MyBatis/Nginx | 实验设计相关资源 |
| `harmonyos` | HarmonyOS | 鸿蒙系统开发学习 |
| `Testjava` | JavaSE | Java测试项目 |

## 技术栈

- **后端框架**: Spring, SpringMVC, SpringBoot, MyBatis
- **数据库**: MySQL, MongoDB, Redis, Hive
- **消息队列**: RabbitMQ
- **测试工具**: Selenium, RestAssured
- **其他**: JDBC, HarmonyOS

## 快速开始

1. 克隆项目
```bash
git clone https://github.com/ZxlDragonDoctor/java-.git
```

2. 进入项目目录
```bash
cd java技术学习记录仓
```

3. 根据需要进入对应的子项目目录进行学习
